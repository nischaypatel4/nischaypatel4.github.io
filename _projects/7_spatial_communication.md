## Research context

**COSMIC Lab · IIT Kanpur · Aug–Nov 2025**  
Supervised by **Prof. Hamim Zafar**. Developed as a **CS690 Computational Genomics final project**.

This project explored how cancer-associated changes in cell-cell communication can be studied while accounting for the physical proximity of sender and receiver cells.

## Approach

Using normal-breast and breast-cancer Visium reference datasets, the framework operated on spot-level ligand–receptor interaction matrices generated by **COMMOT**.

- A **Mann–Whitney** baseline compared interaction-score distributions across conditions.
- An adaptation of the existing **scDisInFact** model used ligand–receptor interaction vectors to disentangle shared and condition-specific latent factors.
- Model-based **ΔLR scores** compared observed cancer interactions with normal-condition counterfactual predictions.
- Distance and neighborhood features supplied spatial constraints, allowing comparison of spatial and non-spatial variants.

The repository provides an implementation notebook, report, presentation, and spatial visualizations, with **per-member contributions** documented in the report.
